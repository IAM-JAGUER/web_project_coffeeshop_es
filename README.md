# Triple Espresso

Página web de una cafetería de especialidad ubicada en Triple Peaks. El sitio incluye un encabezado con información de horarios y dirección, una sección de reserva con formulario interactivo, y un pie de página con enlaces a redes sociales.

## Tecnologías utilizadas

- HTML5 semántico
- CSS3 (Flexbox, posicionamiento, transiciones)
- Metodología BEM para naming de clases
- Google Fonts (Inter, Noto Serif)
- normalize.css

## Planes de mejora

- Agregar una sección de menú con los productos y precios de la cafetería, obtenidos dinámicamente desde un archivo JSON.
- Implementar un mapa interactivo con la ubicación del local usando la API de Google Maps o Leaflet.
- Añadir validación del formulario con JavaScript en el lado del cliente antes del envío.
- Hacer la página completamente responsive para dispositivos móviles y tabletas.
